# Есть дефект или нет

Репетиционное решение для трека компьютерного зрения HackAlem AI. Скрипт принимает путь к одной картинке и печатает результат классификации: `OK` или `DEFECT`.

Решение намеренно простое: оно не использует ML-модель и внешние API. Правило такое: если в изображении достаточно много красных пикселей, считаем, что на картинке есть дефект. Иначе считаем изображение нормальным.

Требуется Python 3.8+. По умолчанию дефект определяется, если доля красных пикселей в изображении не меньше 8%.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python detect_defect.py ok.png
python detect_defect.py defect.png
```

Порог можно изменить через аргумент `--threshold`:

```bash
python detect_defect.py defect.png --threshold 0.10
```

## Ожидаемый результат

Для тестовых изображений из репозитория:

```bash
python detect_defect.py ok.png
# OK

python detect_defect.py defect.png
# DEFECT
```

## Что использовано

- Python
- Pillow для чтения изображений
- Простое правило по доле красного цвета

Собственных моделей, внешних датасетов и API в решении нет.
